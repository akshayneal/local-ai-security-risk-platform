# SYNTHETIC Northstar Learning Cooperative SOC playbook v1
For suspicious authentication, preserve the supplied SigninLogs event identities and compare exact account, device, timestamp and result. Do not join different accounts merely because events are close together. Missing MFA or approval evidence must stay unknown.

Procedure: request the change record from the incident owner and compare the scheduled inventory window. A legitimate alternative is authorized maintenance, but an operator claim is not independent approval. If corroborated malicious activity affects the critical catalog service, propose escalation to the incident owner. Isolation or account disablement needs explicit human authorization; this advisory application cannot execute either action.
