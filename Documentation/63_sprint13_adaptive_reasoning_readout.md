Stable main/tag remain separate; no merge, PR, tag or release is authorized.

The new adapter reads an explicitly supported synthetic JSON string plus a
separate application-reviewed context. It preserves the exact eligible source
string, typed scalar values, source revision and outer field/JSON pointer. It
compares a narrow relationship using Python and emits a source-attributed
deterministic sentence. No existing public endpoint or dashboard imports it.
The outer path corresponds to `raw_log`, `human_review_process` or
`human_oversight[0]`; this experiment does not silently parse ordinary legacy
prose or migrate public request/response contracts.

- SOC: one declared event versus one reported authorization, using exact
  operation, principal, asset, endpoint and inclusive timezone-aware time window.
  Result/amount/source/destination are retained. A failed out-of-scope operation
  is an attempted declared scope mismatch, not a completed transfer or intrusion.
- Governance: explicit reviewed typed requirement versus the same action's
  reported implementation state/timing and bounded sample. Proposed, absent,
  unknown and reported implemented remain distinct. Policy prose is not parsed.
- AI Security: one selected tool, its declared directed model path, consequential
  capabilities, invoker and gate state/timing. Read-only/human-invoked/no-declared-
  path cases are outside this specific predicate, not findings of safety.

Outcome ontology separates declared mismatch/alignment, underdetermined,
conflicting claims, not applicable and projection unavailable. It does not assign
severity, authenticate sources/permission, verify deployed behavior, approve a
deployment or execute an action. Hashes identify snapshots, not trust or anonymity.
The local application still has no authenticated multi-user authorization.

## Diagnosis and adaptive development

The [historical failure map](adaptive_security_reasoning_v1/historical_failure_map.md)
inspects actual Sprint 12 wire prompts, raw visible replies, canonical panels,
rubric and exports. It covers every required case plus extra controls. Those
historical cases were not regenerated, rescored or used as fresh validation.
Correctly extracted facts were sometimes compared incorrectly. Source uncertainty
was also substituted for a concrete mismatch, while matching labels concealed
bad explanations. JSON decoding alone is therefore an insufficient diagnosis.

The prospective [plan](62_sprint13_adaptive_reasoning_plan.md),
[rubric](../evals/adaptive_security_reasoning_v1/rubric.md), literal freezes and
append-only [decision log](adaptive_security_reasoning_v1/decision_log.jsonl)
separate development adaptation from diagnostic qualification. Pre-freeze
prototype probes were unqualified authoring diagnostics: some exact transient
source revisions were not pinned. Their failing inputs/test counts are retained
as regression evidence, not frozen efficacy measurements.

Recorded prototype failures included contradictory reported control state,
mislabeled counterevidence, null counterclaim asymmetry, invalid alternate enum/
range values, forged commentary digest, mismatched snapshot retention, malformed
timezone normalization, irrelevant graph counterclaims and Python's `True == 1`
defeating type-insensitive report equality. The new regression tests preserve
these failures; exports now compare type-sensitive canonical serialization.
Runtime review also exposed arbitrary output namespaces, interrupted dual-ledger
reservation gaps and unverified replay artifacts; the new isolated transport
rejects them before further dispatch rather than repairing history.

M and H use identical eligible raw source, nested premises, question, response
schema and non-thinking runtime. M proposes the relationship. H additionally
receives Python's comparison; that is the one-variable paired contrast. Both
remain unverified model proposals. This is not a paired rerun of the released
analyzers or Sprint 12 scores. Different question/output semantics, synthetic
schema, prompt and case construction confound historical model comparisons.
D requires no model to produce the core comparison/report.

Application reports withhold arbitrary generated commentary. A valid schema and
eligible premise ID cannot prove that prose is entailed. Model outputs and their
failures remain in evaluation artifacts for authored/later human review. No
question, rationale or model label can overwrite the canonical comparison,
source status, approval flag or action status.
