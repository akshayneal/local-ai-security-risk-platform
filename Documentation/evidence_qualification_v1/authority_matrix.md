# Source of authority and trust boundaries

All Sprint 14 capability is experimental internal and off by default. No new
endpoint, navigation claim or document access grant exists.

| Field or claim | Application source | What it establishes and what it cannot establish |
| --- | --- | --- |
| Exact source bytes, hash and row/field | Original supplied upload, bounded parser, deterministic lineage | A reproducible supplied assertion; no authenticity, anonymity or independent event verification |
| Stable internal source identity and revision | Separate application-side SourceReview in the internal synthetic demonstration | Identity within that reviewed snapshot; content cannot self-assign identity |
| Current revision, revocation, classification | Separate current review snapshot rechecked at use/export | Evidence eligibility at that snapshot; no authenticated institution or multi-user IAM |
| Workflow/question/time applicability | QualificationScope plus reviewed workflows/questions/effective window | Bounded applicability; no source-body grant or inferred date |
| Accepted role and requirement review | Explicit application-reviewed synthetic source role and affirmative requirement review | An eligible supplied rule assertion; no proof that an independent human approved a live action |
| Existing organizational metadata | ReviewedMetadata, DocumentReview, registry current-version gate and WorkspaceConfig | Existing SOC/AI Risk document eligibility; no new AI Security organizational retrieval path |
| Source assertion value | Original telemetry or strict synthetic body | Unverified observed/reported value; no real-world confirmation |
| Entity association | Exact typed event/principal/asset/process creation/resource/time scope checks | A bounded relationship between supplied assertions; IP/name/proximity alone is insufficient |
| Comparator verdict | Unchanged adaptive_semantics project plus explicit derived lineage | Narrow declared scope relationship; no severity, compromise, transfer completion or operational authorization |
| Report/export content | Deterministic reconstruction against original bytes and supplied current reviews | Report integrity; no independent semantic truth or arbitrary model-prose certification |
| Analyst correction/review | Existing request/session/case-bound Inspector lineage | Unauthenticated local analyst entry, not permission or institutional authority |
| Permission, actual deployed control, executed action | Not established by this path | Approval is never granted; no action is executed |

Existing retrieval filters workflow/access/policy/date/current version before
ranking. Errors do not enable a less restrictive fallback. Support requirements
need applicable policy authority; implementation needs separate appropriate
evidence. This sprint adds no registry and does not change those paths.

The pure-function caller is inside the application's trust boundary. It must
supply the current review snapshot separately from request content. There is no
authentication service protecting an arbitrary Python caller who can forge all
arguments. A fixture's public_synthetic classification merely limits this
demonstration; it is never treated as proof that a real source is authentic.

Raw source_id, revision/current/approved/authorized fields, JSON-looking CSV cells,
retrieved policy prose, audit messages and hostile annotations cannot create a
reviewed permission. Structural authority injection is refused. Untrusted natural
language remains source data with no route to instructions. Policy requirements,
implementation assertions, recommendations and actions remain separate roles.
